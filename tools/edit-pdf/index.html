Frequently Asked Questions

Are my confidential PDF documents safe from upload leaks?

Yes. The entire editing process runs in your browser memory using `pdf-lib`. No files are uploaded to any external servers, ensuring complete confidentiality.

How do I rearrange pages using this editor?

Once you select a PDF, cards representing each page will appear. Simply drag and drop the cards into the desired sequence, or click their deletion buttons to remove specific pages completely.

Can I add multiple annotations to a single document?

Yes. The tool overlays custom text (like "CONFIDENTIAL" or page stamps) onto all remaining pages of the PDF document using the formatting options you define in the control panel.

Does this tool support password-protected PDF files?

If the PDF is password-protected, you must decrypt it first using our **Unlock PDF** tool before editing. The editor cannot load restricted streams directly without correct keys.

Is there a file size restriction for PDF uploads?

We recommend documents under 40MB for optimal memory consumption during client-side rendering.

Technical Specifications

Understanding PDF content layers and stream manipulations.

Editor Action Technical Process Description Resulting PDF Stream Structure
**Page Rearranging** Manipulates page tree array nodes `/Pages` index list Updates root catalog indices mapping new sequences
**Page Deletion** Prunes reference nodes from page dictionaries Reduces file footprint and cleans page tree arrays
**Text Annotation** Appends content stream object `/Contents` layer to page coordinates Draws text characters with vector coordinates over existing streams
**Metadata Pruning** Removes object descriptors and update streams Flattens incremental edits into a single generation layer
