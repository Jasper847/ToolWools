Frequently Asked Questions

How does PDF encryption protect my documents?

Adding a User password encrypts the document file stream using secure hashes. The PDF reader will block all rendering until the user enters the correct security key.

What is the difference between User and Owner passwords?

A **User Password** blocks read access, requiring users to authenticate before reading pages. An **Owner Password** restricts operational permissions like printing, copying, and layout changes without blocking read access.

Are my files uploaded to the web to perform encryption?

No. Encryption algorithms run client-side in browser memory using `@pdfsmaller/pdf-encrypt`. Your file and passwords never traverse the network.

Can my passwords be retrieved if I forget them?

No. To ensure absolute privacy, we store zero logs, session histories, or metadata. Be sure to note your passwords safely, as they cannot be recovered by us.

Does this tool support high-strength AES-256 standard encryption?

Yes. The client-side encryption module uses standard RC4 128-bit and AES-128/256 compatible headers compliant with universal PDF reader applications.

How the Protect PDF Works

Understanding permissions mapping configurations in standard PDF file tables.

Security Option Flag Value (Bitwise) Operational Restriction Level
**Allow Printing** Bit 3 (Value: 4) Enables document rasterization to hardware print drivers
**Allow Text/Image Copying** Bit 5 (Value: 16) Permits clipboard captures and text extraction crawlers
**Allow Modifications** Bit 4 (Value: 8) Enables page rearranging, text edits, and annotations
**Encryption Tiers** Standard V2 / R3 / R4 AES-128/256 bitwise key expansion algorithms
