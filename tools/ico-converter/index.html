Frequently Asked Questions

How does the client-side image processing work?

The tool uses HTML5 Canvas APIs to perform operations such as scaling, cropping, compression, and format encoding locally in your browser memory without server uploads.

Are there any image file size limits?

Because the conversion happens locally, there is no server-imposed file size limit. However, processing exceptionally large images (e.g., 50MB+) depends on your device's memory.

What output image formats are supported?

You can convert and optimize images between PNG, JPEG, WEBP, and ICO formats depending on the specific tool features.
